# CSI3480-Password-Manager

Password Manager and Generator is a website that give users secure passwords on emails, bank accounts, games, and social media platforms. The Password Manager manages the users passwords from different sites or apps that users have been visiting. In order for the users to access their passwords from other sites or apps, they will need to create their own Master Password to unlock their Vault. The Password Generator will generate a strong and complex password for the users using a range character length from 8 to 32. 

To run our project, open vs code then downloads LiveServer which is an vs extension. Once the LiveServer is done installing, check in the bottom right which you see is "Go Live". That will open up your browser through a local host.
